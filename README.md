# Python Turtle Graphics

Ten designs drawn with Python's `turtle` module.

## What's inside

- Heart, Rangoli, Star, Spiral star, Octagonal design
- Donut, Rectangular graphics, Cool design, Coronavirus graphic, Flower

## How to use

Run any file with `python <file>`; a turtle window opens and draws the design.
